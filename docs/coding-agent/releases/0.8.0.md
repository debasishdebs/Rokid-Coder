# Rokid-Coder 0.8.0 (pre-release, 2026-11-15)

This is the first tagged Rokid-Coder build. It covers Plans 1–5. It has not been through device testing, and it is not on the Play Store; 1.0.0 is the Play Store release (Plan 6).

| Component | Version |
|---|---|
| agentd, the laptop helper (`agentd`, `rk`) | 0.8.0 |
| Claude Code plugin `rokid` | 0.8.0 |
| Codex plugin `rokid` | 0.8.0 |
| Agents phone plugin (Nexus plugin) | 0.8.0 (versionCode 800) |
| Nexus phone-hub and glasses-hub (upstream fork) | 1.8.1, unchanged |

What it does:
- Claude Code and Codex sessions appear on the glasses: progress, approvals, questions, Done, voice replies, approval modes.
- `rk claude` / `rk codex` launchers can compact, change model and reply at any time.
- Links are pinned TLS only, mutual on both paths. A pairing signs out after 14 days unused. Pairing is guided on the phone and on the glasses.
- The phone keeps an alert history. The sound for each alert type is configurable (Speak, Chime or Silent). Each question gets its own card. Long voice replies are condensed on screen and sent in full.
- The OpenClaw provider is removed.

Known gaps: the device checklist has not run yet (`docs/coding-agent/claude/plan/2026-11-14-plan-2-device-checklist.md`); the phone-hub build needs `../CxrGlobal`; one flaky Codex reconnect test remains.

Versioning: Rokid-Coder components share one version. Android versionCode = MAJOR·10000 + MINOR·100 + PATCH, the same scheme as the Nexus hubs.
