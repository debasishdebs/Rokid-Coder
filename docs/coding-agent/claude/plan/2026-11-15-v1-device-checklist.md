# Rokid Coder 1.0: device checklist

Tested build: <rc tag>
Final reviews: <6a execution review file>, <6b execution review file>, <6c execution review file>
ROKID_RK_WINDOWS_VERIFIED: <yes|no>

This is the hardware gate for 1.0.0 (6c T13). It is run by the user, on the bytes of one release candidate, and `scripts/release-gate.mjs` reads it as committed on `release/1.0.0`. Nothing is published until every required row is PASS for that rc.

## How to use this file

- Install from the rc's draft prerelease only, never from a local build: the phone app, the glasses app (from the phone), and the computer installer for each platform.
- Run each row's steps. Put the rc tag you ran it on in `Tested on` and `PASS`, `FAIL`, `N/A` or nothing in `Result`. Put what you saw in `Notes`, and nothing secret: never a token, a steering secret, a pairing line or a full fingerprint.
- The header: the controller fills `Tested build` (the rc tag) and `Final reviews` (the 6a, 6b and 6c execution reviews, in that order) before the run. `ROKID_RK_WINDOWS_VERIFIED` is `yes` only when every `LAUNCH-WIN-*` row and `WINS-W9` are PASS, and `no` otherwise. With `no`, 1.0 ships with the Windows launcher hint (U33).
- Required rows (`Required = yes`) must all be PASS. `ALERT-*`, `INSTALL-*` and `PAIR-*` are the smoke rows and must be tested on the final rc itself. Rows with `Required = no` are recorded for the next release and never block.
- Platform is `macOS`, `Windows (WSL)` or `phone/glasses`. CLI is `Claude Code`, `Codex` or `—`. IDs are unique; do not rename or remove a row.

## Setup for all checks

- A phone with the rc phone app, Rokid glasses connected through Hi Rokid, and the glasses app installed from the phone.
- One Mac (macOS 13 or later) and one Windows 11 22H2 or later computer with WSL 2 (Ubuntu), each with the rc installer. Claude Code and Codex on each.
- The phone and the computers on the same Wi-Fi, and Tailscale on all of them for the rows that say so.
- "Plugin mode" is a plain `claude` or `codex` session attached with `/rokid:on` (`rokid:on` in Codex). "Launcher mode" is `rk claude` or `rk codex`. On Windows, every command runs inside WSL.
- Every new pairing shows a code on the phone and the computer. Confirm on the phone only when both show the same code.
